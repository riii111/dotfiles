# 調査の進め方

参照文書にこの文書がある起動は、調査の仕事として扱う。
成果はローカルのファイルだけとし、リポジトリには残さない。

- 割り当てられたworktreeでコード・履歴・GitHubを読んで調べる。
  branch・commit・push・PRは作らず、worktreeのファイルも変えない。
- 調べることと背景は、管理元の文書と決めたことのメモから読む。
  メモがIssue本文と食い違う場合は、メモを優先する。
- 結果は`~/agent-desk/research/<taskIdの英数字・.・-以外を_に置き換えた名前>.md`に書く。
  メモに書き先があれば、そちらを使う。
  サンドボックスで書き込みが拒否されたら、サンドボックス外で書く。
- ファイルには、結論、根拠（参照したPR・コード・資料へのリンク）、決めきれなかった点と選択肢を書く。
  読み手はownerで、判断に使う資料として書く。
- 独立レビューと必須検証はしない。
- 完了報告の冒頭に書いたファイルの絶対パスを書き、結論を数文で添える。
