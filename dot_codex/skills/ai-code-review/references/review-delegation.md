# 調査の分担

変更量・影響範囲・独立して調べられる論点に応じて、subagentを積極的に使う。
本体は問いの分解、担当間の接続、根拠の検証と最終判断を担う。

- 独立した問いは担当を分け、並列に開始する。
  共通の文脈を一緒に追う必要がある問いはまとめ、小さく分割の利点がない調査は本体で行う。
- 人数は独立した担当範囲と実行環境の同時起動上限に合わせ、結果に応じて見直す。
  ファイル数や固定の役割だけで決めない。
- モデルと推論強度は環境のsubagent設定を使い、ユーザーが指定した場合だけ上書きする。
- 担当には問い・固定版の資料・該当規約・必要な前提を渡し、会話履歴全体は継承しない。
  共通資料は一度取得して共有し、依存する調査は必要な証拠がそろってから進める。
- 担当は結論・根拠のファイルと行・未確認事項を返す。
  本体が根拠と担当間の矛盾・抜けを確認し、重複を除いて統合する。

分担の承認や注目点を定型質問せず、答えがレビュー結果を変える場合だけユーザーに確認する。
