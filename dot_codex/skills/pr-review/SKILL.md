# PR Review

他者PRをレビューし、取り込み可否と投稿可能な指摘の下書きを返す。
実装・PRへの投稿・返信・レビュー送信は行わない。
Pendingへの保存はユーザーが `review-draft` を明示した場合だけ、そのSKILLで行う。
resolveの許可は推測しない。

## 対象と再依頼の紐づけ

依頼されたPR・base・head・checkoutを確認し、指定された版を維持する。
最初に、対象PRのURLで `pr-wake review link <PRのURL>` をサンドボックス外で一度実行する。
Codexは `sandbox_permissions: require_escalated` を付け、Claudeはそのまま実行する。
パイプ・リダイレクト・`cd`などを付けず単独で実行する。

他人からの依頼かどうかはコマンドが判定する。
出力が `linked` で始まればレビューを続ける。
`skipped` で始まる場合と失敗した場合は、再実行せずレビューを続け、結果に「再依頼はこのスレッドに届かない」と一言添える。
この紐づけは再レビュー依頼用で、返信の監視や `watch` への登録は行わない。

## レビューの選択

PRのタイトルだけで決めず、変更ファイルと内容から次のSKILLを読み、その手順でレビューする。

| 対象                                   | 内部SKILL                                    |
| -------------------------------------- | -------------------------------------------- |
| 実装・テスト・設定・運用手順などの変更 | [ai-code-review](../ai-code-review/SKILL.md) |
| ADRの追加・変更                        | [adr-review](../adr-review/SKILL.md)         |

混在するPRは両方を使う。
確認したbase・headと収集済みの証拠を共有し、ADRの決定と実装の整合も確認する。
調査を重複させず、同じ問題の指摘を統合して結果を返す。
内部SKILLへはPR・固定版・checkout・依頼の文脈・前回の指摘を渡す。

## 再レビュー

再依頼はこのチャットの前回結果と照合し、前回の指摘の対応状況と新規指摘を区別する。
対象範囲と判定は内部SKILLに従う。
返信への見解だけを求められた場合は、対象スレッドと必要なコード・ADRを確認して見解と返信の下書きを返す。
